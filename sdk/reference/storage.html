Storage#

The Storage module provides a high-level interface for file system operations and persistent data storage. It includes utilities for file handling, directory management, and disk usage monitoring.

Basic usage#

from sdk.storage import Storage

storage = Storage('/flash')

# Get a list of files (handles directory traversal)
for filename in storage.list(path='data/logs/2025'):
    print(filename)

Storage usage#

Monitor available storage to prevent out-of-space errors in long-running applications.

# Unpacking usage attributes
total, used, free = storage.usage
print(f"Total: {total} bytes")
print(f"Used: {used} bytes")
print(f"Free: {free} bytes")

# Accessing attribute by name
print(f"Total: {storage.usage.total} bytes")

File operations#

Files can be handled using a context manager or a decorator. Both methods ensure proper resource management while providing flexibility in structuring your file operations.

The context manager provides direct file access with automatic cleanup, working like Python’s built-in open() but with storage-relative paths.

with storage.open('logs/20250523.log', mode='r') as logfile:
    for line in logfile.readline():
        print(line)

storage.remove('logs/20250523.log')

The decorator pattern wraps functions to automatically manage files, passing the open file as an argument while handling all cleanup.

@storage.file('config.toml', 'w')
def save_config(file: IO, settings: Dict):
    settings = toml.parse(settings)
    file.write(settings)

save_config({"interval": 30, "units": "celsius"})

Size Formatting#

The to_best_size helper automatically scales and formats storage sizes.

from sdk.storage import Storage, to_best_size

storage = Storage('/sd')

total = to_best_size(storage.usage.total, decimals=1)
print(f"Total: {total}")  # Total: 15.4 GB

class Storage(root)#

Manages file system operations under a specified root directory.

This class provides a unified interface for file operations, directory management, and storage metrics. It ensures proper path handling and directory creation for all operations.

Parameters:

root (str)

exists(filename) → bool#

Check if a file exists.

Parameters:

filename (str) – Name of the file to check.

Return type:

bool

Returns:

True if the file exists, False otherwise.

file(filename, mode, encoding='utf-8') → Callable#

Create a decorator for file-based operations.

This decorator manages file opening and closing for the decorated function. It ensures proper resource cleanup even if exceptions occur.

Parameters:

  • filename (str) – Name of the file to operate on.

  • mode (str) – File open mode.

  • encoding (default: "utf-8") – File encoding (default: “utf-8”).

Return type:

Callable

Returns:

Decorator function that manages file operations.

list(path='') → List[str]#

List contents of a directory.

Parameters:

path (str, default: "") – Relative path within the root directory (default: “”).

Return type:

List[str]

Returns:

List of file and directory names in the specified path.

Raises:

OSError – If the directory cannot be listed.

open(filename, mode, encoding='utf-8') → IO#

Open a file with the specified mode and encoding.

This method ensures the file’s directory exists before opening.

Parameters:

  • filename (str) – Name of the file to open.

  • mode (str) – File open mode (e.g., “r”, “w”, “a”).

  • encoding (default: "utf-8") – File encoding (default: “utf-8”).

Return type:

IO

Returns:

File object opened with the specified parameters.

Raises:

OSError – If the file cannot be opened.

remove(filename) → None#

Remove a file.

Parameters:

filename (str) – Name of the file to remove.

Raises:

OSError – If the file cannot be removed.

Return type:

None

property root: str#

Get the base storage directory path.

Returns:

The root directory path.

property usage: DiskUsage#

Get storage usage statistics.

Returns:

DiskUsage tuple containing (total, used, free) space in bytes.

Raises:

OSError – If the storage path is unavailable.

to_best_size(size_bytes, decimals=1) → str#

Convert a byte size to human-readable format.

This function converts a size in bytes to the most appropriate unit (B, KB, MB, GB) with the specified decimal precision.

Parameters:

  • size_bytes (int) – Size in bytes to convert.

  • decimals (default: 1) – Number of decimal places to show (default: 1).

Return type:

str

Returns:

Formatted string with size and unit (e.g., “1.5 MB”).
