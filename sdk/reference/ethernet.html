Ethernet#

The Ethernet module provides a high-level interface for wired network connections with automatic DHCP handling and manual configuration options. It simplifies network management with clean access to connection status and network parameters.

[!WARNING] The Ethernet class is available only if the hardware provides an active Ethernet interface.

Basic Usage#

from sdk.ethernet import Ethernet

eth = Ethernet()

# DHCP configuration (automatic)
eth.connect()

# Manual configuration
eth.connect(
    ip="192.168.1.100",
    gateway="192.168.1.1",
    subnet="255.255.255.0"
)

print(f"Connected: {eth.is_connected}")
print(f"IP Address: {eth.ip}")
print(f"Gateway: {eth.gateway}")

# Disconnect
eth.disconnect()

Class Reference#

class Ethernet(phy_type=None)#

Manages Ethernet network connections and configuration.

This class provides a simplified interface for configuring and monitoring Ethernet connections, with support for static and dynamic IP addressing.

Parameters:

phy_type (Optional[int], default: None)

connect(ip=None, gateway=None, subnet='255.255.255.0', dns='1.1.1.1') → None#

Configure and establish an Ethernet connection.

This method supports both static IP configuration and DHCP. If IP is provided, a static configuration is used; otherwise, DHCP is enabled.

Parameters:

  • ip (Optional[str], default: None) – Optional static IP address. If None, DHCP is used.

  • gateway (Optional[str], default: None) – Optional gateway IP address.

  • subnet (str, default: "255.255.255.0") – Subnet mask (default: “255.255.255.0”).

  • dns (str, default: "1.1.1.1") – DNS server IP address (default: “1.1.1.1”).

Return type:

None

disconnect() → None#

Disable the Ethernet interface.

This method deactivates the Ethernet connection and releases any allocated network resources.

Return type:

None

property gateway: str#

Get the gateway IP address.

Returns:

The gateway IP address in string format.

property ip: str#

Get the current IP address.

Returns:

The IP address in string format (e.g., “192.168.1.100”).

property is_connected: bool#

Check if the Ethernet connection is active.

Returns:

True if connected, False otherwise.
