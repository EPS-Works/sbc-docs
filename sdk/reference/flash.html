FlashDrive#

The FlashDrive module extends Storage to handle flash storage devices, providing tools for managing partitions while maintaining persistent storage operations.

Basic usage#

from sdk.flash import FlashDrive

# Initialize with flash mount point
flash = FlashDrive('/flash')
data, *_ = flash.mount()

# Access like regular storage
with flash.open('config.toml', mode='w') as file:
    file.write("VERSION='0.0.1'")

with data.open('data.txt', mode='w') as file:
    file.write('persistent data')

Partition Management#

Flash partitions allow to logically separate storage space while using a single physical device. This enables different filesystems, isolated storage areas, or dedicated spaces for specific purposes like logging or configuration.

Partition integrity is mantained through power cycles by storing layout information in a .partitions hidden file.

The mount method prepares all partitions for use. It returns all the extra partitions as ready-to-use Storage instances.

partitions = flash.mount()

# Each partition is a regular Storage instance
for partition in partitions:
    print(f"Partition at {partition.root}")
    print(f"Free space: {partition.usage.free} bytes")

The format method completely erases the flash device and prepares it as a single storage area. This is useful when repurposing storage or recovering from filesystem errors.

flash.format()

Create new partitions specifying the name and size, and choose between FAT (default) or LFS2 filesystems. The system handles block alignment automatically.

[!CAUTION] Creating a new partition will erase all existing data on the flash storage.

partition = flash.partition(name='logs', size=1024 * 1024)
print(f"Created partition with {partition.usage.total} bytes")

The class enforces 4096-byte block alignment for optimal flash memory performance. Requested sizes are automatically adjusted to the nearest aligned value.

# Requested 1MB (1048576 bytes)
partition = flash.partition('test', 1_048_576)

# Actual size may be less due to block alignment
print(f"Size: {partition.usage.total} bytes")

Class Reference#

FS#

alias of FileSystem

class FlashDrive(root)#

Manages flash storage devices with partitioning capabilities.

This class extends the Storage base class to provide advanced flash storage operations including partition management, formatting, and mounting. It supports both FAT and LittleFS filesystems where available.

Parameters:

root (str)

format() → bool#

Format the flash storage as a single FAT filesystem.

Removes all existing partitions and creates a fresh filesystem. This operation will erase all data on the device.

Return type:

bool

Returns:

True if formatting was successful, False otherwise.

mount() → Tuple[Storage, ...]#

Mount all partitions on the flash storage device.

Reads the partition table and mounts each partition at its designated mount point.

Return type:

Tuple[Storage, ...]

Returns:

Tuple of Storage objects representing mounted partitions, excluding the base partition.

partition(name, size, fs=FileSystem.FAT) → Storage | None#

Create a new partition on the flash storage.

Creates a partition with the specified name and size, formatting it with the requested filesystem type. The partition is created at the end of the available space.

Parameters:

  • name (str) – Name for the new partition.

  • size (int) – Size of the partition in bytes.

  • fs (FileSystem, default: FileSystem.FAT) – Filesystem type to use (defaults to FAT).

Return type:

Optional[Storage]

Returns:

Storage object for the new partition if successful, None otherwise.

Raises:

ValueError – If name is invalid or there is insufficient space.
