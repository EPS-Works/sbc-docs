Stream#

The Stream module provides a robust interface for processing serial data streams with support for multiple parsers and both synchronous and asynchronous operation. It efficiently manages system resources through configurable throttling and timeout parameters.

When parsing into objects is unnecessary—such as when forwarding data to another interface—enable the raw mode or omit the parsers array to bypass processing overhead.

As a context manager, it ensures proper cleanup of serial buffers and resources upon exit, preventing memory leaks.

Basic Usage#

from machine import UART
from sdk.stream import Stream
from sdk.parsers.nmea import Parser

uart = UART(8, baudrate=115200)

parser = Parser()
with Stream(serial=uart, parsers=[parser]) as stream:
    for nmea in stream:
        print(nmea.name)

Non-blocking listening is supported to allow concurrent handling of multiple data streams while maintaining responsiveness in async applications.

from asyncio import create_task

async def handle_data(uart: UART):
    parser = Parser()
    with Stream(serial=uart, parsers=[parser]) as stream:
        async for nmea in stream:
            print(nmea.name)

create_task(handle_data(uart))

The decorator pattern simplifies stream processing by automatically managing the stream lifecycle.

[!WARNING] Decorator works always in an asynchronous context.

from sdk.stream import stream
from asyncio import create_task

@stream(parsers=[Parser()])
def handle_data(msg, *_):
    print(msg.name)

create_task(forward_ubx(uart))

Class Reference#

class Stream(serial, parsers=None, raw=False, throttle=10, timeout=None, buffer_size=256)#

Serial data stream processor with parser support.

This class provides a high-level interface for reading and processing serial data streams. It supports multiple parsers, configurable throttling, and timeouts. The class can be used as a context manager for automatic resource cleanup and as an iterator for convenient message processing.

Parameters:

  • serial (Serial)

  • parsers (Optional[List[Parser]], default: None)

  • timeout (Optional[int], default: None)

cleanup() → None#

Clean up stream resources.

This method resets the internal buffer. It is automatically called when the stream is closed or garbage collected.

Return type:

None

stream(parsers=None, raw=False, throttle=10, timeout=None, buffer_size=256) → Callable[[Callable[[Any, Serial], None]], Callable[[Serial], Any]]#

Create a message processor decorator for serial streams.

This decorator transforms a function into an automatic message processor for serial data streams. It handles stream initialization, iteration, and cleanup, calling the decorated function with each parsed message.

Parameters:

  • parsers (Optional[List[Type[Parser]]], default: None) – Optional list of Parser classes for message parsing.

  • raw (default: False) – If True, pass raw bytes instead of parsed messages.

  • throttle (int, default: 10) – Milliseconds to wait between reads (default: 10).

  • timeout (Optional[int], default: None) – Optional timeout in milliseconds for read operations.

  • buffer_size (int, default: 256) – Size of internal buffer (default: 256).

Return type:

Callable[[Callable[[Any, Serial], None]], Callable[[Serial], Any]]

Returns:

A decorator that wraps a function to process messages from a serial stream.

The decorated function should accept 2 arguments:

  • msg: The parsed message or raw bytes

  • serial: The Serial interface instance
