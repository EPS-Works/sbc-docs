Ublox#

The Ublox module provides a high-level interface for controlling Ublox ZED-F9P GNSS receivers via UART. It extends the base GNSS interface to provide specific configuration and streaming control using the UBX protocol.

Basic Usage#

from sdk.xbee import XBeeSocket
from sdk.modules.gnss import Ublox

# Initialize Ublox receiver
socket = XBeeSocket(port=8, baudrate=115200)
gnss = Ublox(socket=socket)

# Optionally configure message streaming
gnss.stream(messages=["NAV-PVT", "NAV-SAT"], port=1)

while True:
    if data := gnss.read():
        print(data)

GNSS sockets other than main include dedicated power pins. You can manage power using the DigitalIO module:

from sdk.dio import DigitalIO
from sdk.xbee import XBeeSocket
from sdk.modules.gnss import Ublox

# Initialize Ublox receiver on GPS2 socket
power = DigitalIO(pin="PWR_GNSS")
socket = XBeeSocket(port=1, baudrate=115200, power=power)
gnss = Ublox(socket=socket)

gnss.on()

Class Reference#

class Ublox(socket)#

Controller for Ublox ZED-F9P GNSS receivers.

This class extends the base GNSS interface to provide high-level configuration of UBX protocol messages and streaming behavior. It handles enabling and disabling message outputs on specified ports using UBX-CFG-VALSET commands.

Parameters:

socket (XBeeSocket)

autobaud(timeout=100) → None#

Auto-detect the baudrate of the connected GNSS receiver.

This method attempts to detect the correct baudrate by sending a test message and checking for acknowledgment across common baudrates.

Parameters:

timeout (Optional[int], default: 100) – The maximum time to wait for the ACK response in milliseconds.

Return type:

None

Returns:

The detected baudrate, or None if no baudrate was detected.

config(data, layer=0x01) → None#

Configure the GNSS receiver using UBX-CFG-VALSET messages.

This method sends configuration data to the receiver and waits for acknowledgment.

Parameters:

  • data (List[Tuple[int, Tuple[int, str]]]) – List of tuples containing (Key ID, value) pairs to configure.

  • layer (int, default: 0x01) – The configuration layer to modify (default: RAM).

Raises:

OSError – If the configuration cannot be applied or acknowledgment is not received.

Return type:

None

halt(messages, port) → None#

Stop streaming GNSS messages.

Parameters:

  • messages – List of message types to stop streaming.

  • port – The port to stop streaming messages to.

Raises:

  • ValueError – If any message type is not supported.

  • OSError – If the stream cannot be started.

Return type:

None

stream(messages, port, frequency=1) → Callable[[Any], None]#

Start streaming GNSS messages.

This method configures the GNSS receiver to stream specified messages to a port at the given frequency.

Parameters:

  • messages – List of message types to stream.

  • port – The port to stream messages to.

  • frequency (Optional[int], default: 1) – Optional frequency in Hz for message streaming.

Return type:

Callable[[Any], None]

Returns:

A callable that can be used to stop the streaming.

Raises:

  • ValueError – If any message type is not supported.

  • OSError – If the stream cannot be started.
