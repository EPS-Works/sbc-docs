Serial#

The Serial module provides buffer capabilities to manage serial data streams with support for multiple concurrent consumers. SerialBuffer implements an internal ring buffer that allows independent cursors to track different read positions, enabling safe parallel access to the serial data.

[!WARNING] The fixed size circular buffer wraps when it fills up, and new incoming data overrides old. Stale cursors -not actively reading or reading at slow pace- will lose data.

Basic Usage#

from machine import UART
from sdk.serial import SerialBuffer

uart = UART(1, baudrate=115200)
buffer = SerialBuffer(uart, size=128)

data = buffer.read(cursor='__cursor__')
print(f"Received: {data}")

Multiple cursors can be created to access the same serial from independent processes. These cursors use the same interface as the original serial port, making them interchangeable when injected into functions or classes.

[!WARNING] Reading directly from the original serial after creating a buffer will result in race conditions and data loss. Always use buffer cursors whenever multiple access to the serial is required.

from machine import UART
from sdk.serial import SerialBuffer

uart = UART(1, baudrate=115200)
buffer = SerialBuffer(serial=uart, size=128)

decoder = SerialDecoder(serial=buffer.cursor('__reader__'))
logger = DataLogger(source=buffer.cursor('__logger__'))

Class Reference#

class Serial(*args, **kwargs)#

Protocol defining the interface for serial communication.

This protocol specifies the minimum interface required for serial communication implementations. Classes implementing this protocol must provide methods for reading, writing, and flushing serial data.

Read data from the serial port.

Parameters:

nbytes (int | None, default: None) – Number of bytes to read. If None, reads all available data.

Return type:

bytes

The bytes read from the serial port.

  • nbytes (int | None, default: None) – Number of bytes to read. If None, reads all available data.

class SerialBuffer(serial, size=_BUFFER_SIZE)#

Buffered circular serial data reader with multiple cursors.

This class provides a rolling buffer for serial data with support for multiple independent cursors. Each cursor can track its position in the buffer. The buffer automatically wraps around when the end of the buffer is reached.

Parameters:

  • serial (Serial)

  • size (int, default: _BUFFER_SIZE)

cursor(name) → SerialBufferCursor#

Create a new cursor at the current buffer position.

Parameters:

name (str) – Unique identifier for the new cursor.

Return type:

SerialBufferCursor

Returns:

A SerialBufferCursor instance bound to this buffer.

Raises:

ValueError – If a cursor with the specified name already exists.

class SerialBufferCursor(buffer, name)#

Cursor for reading from a SerialBuffer.

This class provides a convenient interface for reading from a specific position in a SerialBuffer. The cursor automatically flushes its position when garbage collected to prevent memory leaks.

Parameters:

  • buffer (SerialBuffer)

  • name (str)
