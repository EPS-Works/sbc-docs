NMEA#

The NMEA class provides capabilities for parsing, validating, and working with NMEA (National Marine Electronics Association) messages from GNSS/GPS devices.

[!TIP] For typical usage, the NMEA parser integrates directly with the Stream class that automatically handles message framing, checksum validation, and parsing, delivering ready-to-use NMEA message objects.

Basic usage#

from sdk.parsers.nmea import NMEA, Parser

# Parse NMEA messages
gga_data = b"$GPGGA,092750.000,5321.6802,N,00630.3372,W,1,8,1.03,61.7,M,55.2,M,,*76\r\n"
if NMEA.is_valid(gga_data):
    gga = NMEA.parse(gga_data)
    print(f"Lat: {gga.lat:.6f}  Lon: {gga.lon:.6f}")

# Stream processing
parser = Parser(callback=lambda msg: print(msg.msg_id))
while data := reader.read():
    parser.find(data)

The parser includes built-in support for essential NMEA messages including GGA, GLL, RMC, GSV, GSA, and GST. Additional message types can be easily registered when needed, allowing extensibility while keeping the parser’s core lightweight.

Registering custom messages#

Each NMEA message type is defined by its fields (name, type, and parsing rules) and an optional custom parser for complex formats:

from sdk.parsers.nmea import NMEA, Field

NMEA.register(
    msg_id='ROT',
    fields=[
        Field('rate_turn', type=float, parse=None),
        Field('valid', type=bool, parse=lambda value: value == 'A'),
    ]
)

Field parameters:

  • name: The field’s key in the parsed output

  • type: The expected Python type (e.g., float, str)

  • parse: Optional function to convert raw values (e.g., coordinate DDMM to degrees)

Class Reference#

class NMEA(msg_id, talker, **kwargs)#

NMEA message.

This class provides high-level methods to validate, parse and handle NMEA messages. It supports both standard and custom NMEA message types.

Parameters:

  • msg_id (str)

  • talker (str)

classmethod checksum(data) → int#

Calculate the NMEA checksum for the given data.

Parameters:

data (bytes) – The byte sequence over which to calculate the checksum.

Return type:

int

Returns:

An string representing the XOR hex checksum of the provided data.

classmethod is_valid(data, msg=None) → bool#

Check if data is a valid NMEA message.

Parameters:

  • data (bytes) – A raw NMEA message as bytes.

  • msg (Optional[str], default: None) – The expected NMEA message type.

Return type:

bool

Returns:

True if the message is valid, False otherwise.

classmethod parse(data) → NMEA#

Parse a raw NMEA message into a structured object.

Parameters:

  • data (bytes) – A raw NMEA message as bytes.

  • validate – Whether to validate the message before parsing.

Return type:

NMEA

Returns:

A structured NMEA object.

classmethod register(msg_id, fields, parser=None) → None#

Register a new NMEA message type.

This function allows adding support for custom NMEA message types by registering their field definitions and optional custom parser.

Parameters:

  • name – The message identifier (e.g., “GGA”).

  • fields (List[Field]) – List of Field namedtuples defining the message structure.

  • parser (Optional[Callable[[str], Dict[str, Any]]], default: None) – Optional custom parser function for complex message types.

  • msg_id (str)

Raises:

ValueError – If a message with the same name is already registered.

Return type:

None

classmethod validate(data, name=None) → None#

Validate a raw NMEA message.

Parameters:

  • data (bytes) – A raw NMEA message as bytes.

  • name (Optional[str], default: None) – The expected NMEA message type.

Raises:

AssertionError – If the message is invalid.

Return type:

None

class Parser(callback=None)#

Stateful parser for streaming NMEA data.

This class extends a generic Parser and implements a state machine to parse incoming bytes from a data stream into complete NMEA sentences. It handles validation, buffering, and extraction of structured message data from valid sentences.

Parameters:

callback (Optional[Callable[[NMEA], None]], default: None)

find(data) → Tuple[None | bytes, int | None]#

Find a complete NMEA message in a byte sequence.

Parameters:

data (bytes) – The data to search for a complete NMEA message.

Return type:

Tuple[Optional[bytes], Optional[int]]

Returns:

A tuple containing the found NMEA message as bytes if found, None otherwise, and the position of the message in the data if found, None otherwise. The position is the index of the first byte of the message.

parse(data) → NMEA#

Parse a raw NMEA message into a structured object.

Parameters:

data (bytes) – A raw NMEA message as bytes.

Return type:

NMEA

Returns:

A structured NMEA object.

process(data) → bytes | None#

Process and accumulate data bytes to form a complete NMEA message.

This method appends incoming data bytes to the current message buffer, resetting the buffer when a start delimiter (‘$’) is encountered. It continues to accumulate bytes until a complete message with a valid checksum is detected or the maximum message length is exceeded.

Parameters:

data (int) – The incoming data byte to be processed.

Return type:

Optional[bytes]

Returns:

The complete NMEA message as bytes if a valid message is formed, otherwise None.

reset() → None#

Reset the parser state.

Resets the parser state to its initial state and clears any partial message data. This method is called automatically when a valid message is parsed or when the parser is initialized.

Return type:

None
