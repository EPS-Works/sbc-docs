BNO08x#

The BNO08x module provides a high-level interface to interact with the BNO08x sensor via I2C. The BNO08x is an IMU that fuses data from a 3-axis accelerometer, gyroscope, and magnetometer to provide highly accurate orientation and rotation vectors.

Basic Usage#

from machine import I2C
from sdk.modules import BNO08x

i2c = I2C(3, freq=400_000)

imu = BNO08x(i2c=i2c, reset=1)
imu.reset()

imu.activate(BNO08x.STABILIZED_ROTATION)

while True:
    imu.update()
    roll, pitch, yaw = imu.attitude
    print(f"Roll:{roll:.3f} Pitch:{pitch:.3f} Yaw:{yaw:.3f}")

IMU orientation#

The BNO08x class transforms sensor data to align with the board’s orientation based on the NED (North-East-Down) reference frame. The set_frame(x, y, z) method allows explicit configuration of the SBC’s installed axis directions. This enables accurate compensation for any physical mounting orientation of the board, ensuring that all output measurements are consistently referenced and precisely aligned regardless of installation.

from sdk.modules import BNO08x, Axes

# BNO08x sensor is mounted on the board at 90deg on z from its own reference on the board
mounting_frame = Axes(x='N', y='W', z='U')
imu = BNO08x(i2c=i2c, reset=1, mount=mounting_frame)

# The board is rotated -90deg on y from NED
imu.set_frame(x='D', y='E', z='S')

Class Reference#

class BNO08x(i2c, address=0x4A, reset=None, mount=None)#

Interface for interacting with the BNO080 IMU.

The BNO08x class provides methods for accessing various sensor readings asynchronously, updating data at specified intervals, and managing device reset and configuration.

This class handles the low-level communication with the BNO08x sensor over I2C, including packet formatting, error handling, and data conversion.

Parameters:

  • i2c (MockI2C)

  • reset (int | str | None, default: None)

  • mount (Axes | None, default: None)

property acceleration: Tuple[float, float, float] | None#

Get the current acceleration data.

Returns:

A tuple of (x, y, z) acceleration values in m/s², or None if data is not available or the sensor is not activated.

activate(sensor, interval=100_000) → None#

Activate a specific sensor with the given update interval.

This method enables data collection for the specified sensor type at the given interval.

Parameters:

  • sensor (Tuple[int, int, int]) – The BNO08xSensor to activate.

  • interval (int, default: 100_000) – The update interval in nanoseconds (default: 100_000).

Return type:

None

property angular_velocity: Tuple[float, float, float] | None#

Get the current angular velocity data.

Returns:

A tuple of (x, y, z) angular velocity values in rad/s, or None if data is not available or the sensor is not activated.

property attitude: Tuple[float | None, float | None, float | None]#

Get the current attitude data.

This property calculates roll, pitch, and yaw angles from the stabilized rotation quaternion or the rotation quaternion if the stabilized rotation is not available.

Returns:

An Attitude with roll, pitch, and yaw angles in degrees, or all None if data is not available or the sensor is not activated.

property magnetic_field: Tuple[float, float, float] | None#

Get the current magnetic field data.

Returns:

A tuple of (x, y, z) magnetic field values in microtesla (µT), or None if data is not available or the sensor is not activated.

reset() → None#

Reset the BNO08x sensor.

This method performs a hardware reset of the BNO08x sensor if a reset pin is configured, or a software reset otherwise. It reinitializes the sensor after the reset.

Return type:

None

property rotation: Tuple[float, float, float, float] | None#

Get the current rotation data.

Returns:

A tuple of (w, x, y, z) quaternion values representing the rotation, or None if data is not available or the sensor is not activated.

set_frame(x, y, z) → None#

Set a new reference frame for the BNO08x sensor

Parameters:

  • x (Literal['E', 'W', 'N', 'S', 'U', 'D']) – The x-axis direction.

  • y (Literal['E', 'W', 'N', 'S', 'U', 'D']) – The y-axis direction.

  • z (Literal['E', 'W', 'N', 'S', 'U', 'D']) – The z-axis direction.

Raises:

ValueError – If the provided axes are not valid or do not form a valid right-handed system.

Return type:

None

property stabilized_rotation: Tuple[float, float, float, float] | None#

Get the current stabilized rotatio quaternion data.

Returns:

A tuple of (w, x, y, z) quaternion values representing the stabilized rotation, or None if data is not available or the sensor is not activated.

update() → None#

Update the sensor data.

Polls the BNO080 for incoming sensor data, processing any available packets. The update function will continue reading packets until either data is received or a timeout occurs. The timeout duration is specified by the TIMEOUT constant.

Raises:

OSError – If no data is received within the specified timeout period.

Return type:

None
