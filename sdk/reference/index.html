API Reference#

This section documents all the modules and classes included in the Ardusimple SDK.

The SDK is organized into several modules, each targeting a different area of functionality: hardware access, data streaming, GNSS communication, and common utilities.

Core classes#

Interact with onboard hardware and communication interfaces.

  • AnalogIn – Reads analog voltage levels through ADC.

  • CANBus – Interface for CAN bus communication.

  • DigitalIO – Controls digital pins as input or output.

  • Ethernet – Manages Ethernet connectivity and DHCP/static config.

  • FlashDrive – Exposes onboard flash drive.

  • Forwarder – Forwards serial data between serial interfaces.

  • Led – Controls onboard or external status LEDs.

  • PWM – Outputs PWM signals for dimming, motor control, etc.

  • SerialBuffer – Buffered reader/writer for UART and stream-based interfaces.

  • Storage – Filesystem interface for persistent storage.

  • Stream – Monitors a serial interface and parses all incoming data in real-time.

  • UsbHub – Manage USB hub configuration.

Modules#

Drivers and interfaces for supported hardware modules.

  • Ublox - Interface for u-blox GNSS modules.

  • BNO08x - Drivers for BNO08x IMUs.

Parsers#

Parsers for GNSS protocols.

  • NMEA - Handles standard NMEA 0183 GNSS sentences.

  • UBX - Handles binary UBX messages from u-blox devices.

NTRIP#

NTRIP functionality for RTK corrections over internet.

  • NTRIPClient - Handles connection and data reception.

  • RTKBridge - Forwards correction data over a serial interface.

Utils#

Convenience decorators and helper tools.

  • Encoder - Encodes string using a salt-based substitution cipher.

  • OTA – Simple over-the-air update interface.

  • @retry – Retries a function on failure.

  • @periodic – Runs a function at a fixed interval.

  • @debounce – Debounces repeated calls (e.g. from noisy inputs).

Filters#

Signal processing utilities.

  • ExponentialMovingAverage – Simple exponential moving average filter.
