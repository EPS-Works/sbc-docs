AnalogIn#

The AnalogIn module provides a high-level interface for analog input readings with built-in noise reduction. It handles both raw ADC values and converted voltages, supporting voltage divider circuits for flexible signal conditioning.

Basic Usage#

from sdk.ain import AnalogIn

sensor = AnalogIn("VAIN1", voltage_divider=2.0)

# Read processed values
print(sensor.value)  # Raw ADC (0-65535)
print(sensor.voltage)  # Calculated voltage

Noise Reduction#

Analog signals often contain noise from power supplies, RF interference, or sensor imperfections. Noise reduction stabilizes readings and filters spikes but may slow down sampling and smooth fast signal changes.

This class implements a 3-stage noise reduction: multiple sampling, median filtering and voltage scaling. Adjust SAMPLE_SIZE when you need faster reads or more stable measurements.

sensor.SAMPLE_SIZE = 50 # Faster but noisy readings
sensor.SAMPLE_SIZE = 1000 # Slower but more stable readings

For applications requiring smooth continuous measurements, combine with a signal filter.

from sdk.ain import AnalogIn
from sdk.filters import ExponentialMovingAverage

sensor = AnalogIn("VAIN1", voltage_divider=2.0)
ema_filter = ExponentialMovingAverage(alpha=0.2)

while True:
    raw = sensor.voltage
    filtered = ema_filter.apply(raw)
    print(f'Raw: {raw:.2f}V  Filtered: {filtered:.2f}V')

Class Reference#

class AnalogIn(pin, voltage_divider)#

Provides an interface for reading analog values and voltages from pins.

This class implements noise reduction through multiple sampling and provides both raw ADC values and voltage readings. It supports voltage divider configurations for accurate voltage measurements.

SAMPLE_SIZE#

Number of samples to take for noise reduction (default: 500).

Parameters:

  • pin (str)

  • voltage_divider (float)

property value: float#

Get the filtered analog value.

Reads multiple samples from the ADC and returns the median value to reduce noise by averaging out transient fluctuations.

Returns:

The median value from the sampled analog readings (0-65535).

property voltage: float#

Get the voltage of the analog input.

Calculates the actual voltage using the raw ADC value and the configured voltage divider ratio.

Returns:

The voltage in volts.

class DifferentialAnalogIn(target, ref)#

Provides differential measurements between two analog inputs.

This class calculates the difference between a target and reference analog input, useful for applications requiring relative measurements or noise cancellation.

Parameters:

  • target (AnalogIn)

  • ref (AnalogIn)

property value: float#

Get the differential raw value.

Returns:

The difference between target and reference raw values.

property voltage: float#

Get the differential voltage.

Returns:

The voltage difference between target and reference in volts.
