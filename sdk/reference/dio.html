DigitalIO#

The DigitalIO module provides a high-level interface for digital pin management with built-in event handling. It wraps machine.Pin with safety checks and adds callback support for reactive applications.

Basic Usage#

from sdk.dio import DigitalIO

pin = DigitalIO(25, DigitalIO.OUT)

pin.high()
pin.toggle()

Pin Modes#

Switch between input and output modes with automatic validation. The class prevents invalid operations like setting values on input pins.

pin = DigitalIO(2, DigitalIO.IN)

pin.high() # Will raise an exception

pin.mode = DigitalIO.OUT  # Convert to output
pin.high()  # Now safe to set value

Event Handling#

Attach callbacks for pin state changes RISING | FALLING | CHANGE. Multiple handlers can be registered to different events.

[!WARNING] Use this with caution. Do not rely on attach for long blocking callbacks that run in ISR. More info about writing interrupt handlers.

from sdk.io import DigitalIO

pin = DigitalIO(25, DigitalIO.OUT)

def on_fall(pin):
    print(f"Falling edge detected")

def on_rise(pin):
    print(f"Rising edge detected")

pin.attach(trigger=DigitalIO.FALLING, handler=on_fall)
pin.attach(trigger=DigitalIO.RISING, handler=on_rise)

pin.detach(trigger=DigitalIO.RISING)

Class Reference#

class DigitalIO(pin, mode=Pin.OUT, pull=None, inverted=False, value=False)#

Provides a robust interface for digital I/O operations with event handling.

This class wraps Pin to provide safe state transitions and event handling capabilities. It prevents incorrect operations (e.g., writing while in input mode) and supports multiple event handlers for rising, falling, and change events.

IN#

Input mode for digital pins.

OUT#

Output mode for digital pins.

RISING#

Trigger for rising edge events.

FALLING#

Trigger for falling edge events.

CHANGE#

Trigger for both rising and falling edge events.

Parameters:

  • pin (int | str)

  • mode (int, default: Pin.OUT)

  • pull (int | None, default: None)

attach(trigger, handler) → None#

Register an event handler for pin state changes.

Parameters:

  • trigger (int) – The event type (RISING, FALLING, or CHANGE).

  • handler (Callable[[DigitalIO], Any]) – The function to call when the event occurs.

Raises:

ValueError – If the trigger type is invalid.

Return type:

None

detach(trigger=None, handler=None) → None#

Remove event handlers based on trigger type and/or handler function.

Parameters:

  • trigger (int | None, default: None) – Optional trigger type to filter handlers to remove.

  • handler (Callable[[DigitalIO], Any] | None, default: None) – Optional specific handler function to remove.

Return type:

None

If both trigger and handler are None, all handlers are removed.

Raises:

ValueError – If the trigger type is invalid.

high() → bool#

Set the pin to high state.

Return type:

bool

Returns:

True, indicating the high state.

Raises:

ValueError – If the pin is in input mode.

low() → bool#

Set the pin to low state.

Return type:

bool

Returns:

False, indicating the low state.

Raises:

ValueError – If the pin is in input mode.

property mode: int#

Get the current pin mode.

Returns:

The pin mode (DigitalIO.IN or DigitalIO.OUT).

set(value) → bool#

Set the pin output state.

Parameters:

value (bool) – True for high, False for low.

Return type:

bool

Returns:

The value that was set.

Raises:

ValueError – If the pin is in input mode.

toggle() → bool#

Toggle the pin state between high and low.

Return type:

bool

Returns:

The new pin state (True for high, False for low).

Raises:

ValueError – If the pin is in input mode.

property value: bool#

Get the current pin state.

Returns:

True if the pin is high, False if low.
