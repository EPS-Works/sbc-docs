UBX#

The UBX class provides capabilities for parsing, validating, and working with UBX messages from GNSS/GPS devices.

[!TIP] For typical usage, the UBX parser integrates directly with the Stream class that automatically handles message framing, checksum validation, and parsing, delivering ready-to-use UBX message objects.

Basic usage#

from sdk.parsers import UBX

data = b"\x07\x02\x19\n\x17\xb5b\x05..."

UBX.activate('NAV-PVT')

if UBX.is_valid(data):
    pvt = UBX.parse(data)
    print(f"Lat: {pvt.lat:.6f}  Lon:{pvt.lon:.6f}")

[!WARNING] To reduce memory footprint, messages are not available by default and must be lazily activated using the UBX.activate() method.

The parser includes built-in support for essential UBX messages including ACK-ACK, ACK-NAK, MON-MSGPP, MON-VER, NAV-CLOCK, NAV-COV, NAV-DOP, NAV-EOE, NAV-GEOFENCE, NAV-HPPOSECEF, NAV-HPPOSLLH, NAV-ODO, NAV-PVT, NAV-RELPOSNED, NAV-SAT, NAV-SIG, NAV-STATUS, NAV-SVIN, NAV-TIMEGPS, NAV-TIMEUTC, NAV-VELECEF, NAV-VELNED, RXM-RAWX, RXM-RTCM, RXM-SFRBX, TIM-TM2, UBX-CFG-VALSET, and UBX-CFG-VALDEL.

Additional message types can be easily registered when needed, allowing extensibility while keeping the parser’s core lightweight. Registered messages are automatically activated.

Each UBX message type is defined by its name, class id, message id and fields (name and format).

from sdk.parsers.ubx import UBX, Field, Format

UBX.register(name="ACK-ACK", cls=0x05, msg_id=0x01, fields=[
    Field("clsId", format=Format.U1),
    Field("msgId", format=Format.U1),
])

class Field(name, format)#

class Format#

Format specifiers for binary data packing and unpacking.

This class provides format specifiers for various data types used in UBX messages, including integers, floats, strings, and padding bytes.

class Message(firm, fields)#

Defines the format and structure of a UBX message.

This class handles the binary format of UBX messages, including fixed and repeated fields, and provides methods for parsing and serializing message data.

Parameters:

  • firm (Tuple[int, int])

  • fields (List[Field | Repeat])

class UBX(name, **kwargs)#

UBX protocol message parser and generator.

This class implements the UBX protocol parser interface, providing methods for finding, validating, and parsing UBX messages. It supports message checksum validation and proper message framing.

class UBXParser#

Stateful parser for streaming UBX data.

This class extends a generic Parser and implements a state machine to parse incoming bytes from a data stream into complete UBX sentences. It handles validation, buffering, and extraction of structured message data from valid sentences.

Find the first UBX message in the given data.

Parameters:

Return type:

Tuple[bytes | None, int]

Returns:

A tuple containing the first UBX message found in the data and the position of the message in the data, or both None if no message is found.

UBX

process(data) → bytes | None#

Process and accumulate data bytes to form a complete UBX message.

This method appends incoming data bytes to the current message buffer, resetting the buffer when a start delimiter is encountered. It continues to accumulate bytes until a complete message with a valid checksum is detected or the maximum message length is exceeded.

Parameters:

data (int) – The incoming data byte to be processed.

Return type:

bytes | None

Returns:

The complete UBX message as bytes if a valid message is formed, otherwise None.

reset() → None#

Reset the parser state.

Resets the parser state to its initial state and clears any partial message data. This method is called automatically when a valid message is parsed or when the parser is initialized.

Return type:

None
